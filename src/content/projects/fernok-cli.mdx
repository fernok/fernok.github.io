这是一个还在构思阶段的工具，还没有公开仓库。

## 问题

写一篇新文章需要做这些事：

1. 想文件名；
2. 复制 frontmatter 模板；
3. 填日期、标签、描述；
4. 生成分享图；
5. 本地预览；
6. 提交并推送。

这些步骤都不难，但重复次数多了就会烦。fernok-cli 想把这些动作收进一个命令。

## 设想的命令

```bash
# 新建文章，交互式填写 frontmatter
fernok new "用 Astro 做内容站点"

# 检查所有内容的 frontmatter 与链接
fernok check

# 生成分享图
fernok og --all

# 本地预览并打开浏览器
fernok dev
```

## 设计原则

- **只做这个站点需要的事。** 不做通用静态站点生成器。
- **可组合。** 每个子命令都能单独运行，也能被 shell 脚本调用。
- **不隐藏 Git。** 提交仍然由人决定，工具只负责准备内容。
